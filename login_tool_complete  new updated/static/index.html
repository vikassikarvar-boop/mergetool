Help / Guide

Chhoti-moti baatein jo baar-baar kaam aayengi

🚀 Panel start karna

Windows: run_panel.bat double-click karo → browser me http://127.0.0.1:8765 khul jayega.
Manual: pip install flask requests pycryptodomex phir python panel.py

🔑 Login tips

  • Country wahi chuno jis country ka account hai (ya proxy jis country ka hai)
  • Proxy STICKY hona chahiye — DataImpulse: ports 10000-20000 sticky hote hain (1-120 min, default 30); port 823 bina ;sessid.X ke per-request rotate karta hai (login ke liye bekaar)
  • Old tool wala IPRoyal gateway bhi chalega: http://USER:PASS_country-in_session-XYZ_lifetime-30m@geo.iproyal.com:12321 — country URL se AUTO detect hoti hai
  • IN account = IN exit IP — proxy country account se match na hui to GENERIC_ERROR/risk-block pakka
  • App Profile 449 = DEFAULT: Oct 2026 repo research — instagrapi (aaj push hua) + instagram-cli PR#390 dono 449.0.0.52.84 chalate hain; hamare templates ka bloks hash bhi 449 ka = consistent identity. Device Pixel 8 Pro (Android 14) auto-apply — purane Android 8/9 devices par 449 app install hi nahi hota (mismatch = risk flag)
  • Trust signals (naya): USDID registration (X-Meta-Usdid signed header) + FRESH attestation nonce har run me — pehle September-captured STALE nonce ja raha tha jo IG ke liye bada red flag tha
  • Fresh sticky session chahiye to username me ;sessid.kuchbhi-naya add karo
  • THROTTLED (429) aaye to 45-60 min wait karo — baar-baar retry cooldown badhata hai
  • 2FA_FAIL aaye to script folder me bani debug_2fa_response.json file ka content share karo
  • needs_upgrade wali line PATH A (legacy) ki hai — IGNORE karo, PATH B hi asli login hai

🧰 Naya tool connect karna

tools.json kholo → "tools" array me nayi entry daalo (id, label, script, fields, status_rules) → panel refresh karo. Bas. Script usi folder me honi chahiye.

📊 Status ka matlab

  • SUCCESS session mil gayi — Cookies tab me file dikhegi
  • WRONG_PASSWORD IG ne password reject kiya — sahi password check karo
  • NOT_FOUND username exist nahi karta
  • RECOVERY account disabled ya recovery-funnel — fresh proxy/IP se ek baar retry
  • THROTTLED IP/account par rate-limit — 45-60 min wait
  • GENERIC_ERROR IG ka risk-block ("Unable to log in / unexpected error") — password sahi hota hai; aaj attempts band, phone app se login verify, overnight baad ek retry
  • FALLBACK IG ne flow dead legacy endpoint par bheja (soft-refusal) — 45-60 min wait, ek retry home IP se
  • COOLDOWN LOCK: GENERIC_ERROR ke baad 12h, FALLBACK ke baad 1h, 429 ke baad 45min auto-lock (cooldowns.json) — beech me chalane par tool khud rok deta hai; Force = bypass (recommended nahi)
  • SUSPENDED session mili lekin account restricted — use nahi hogi
